Concept notes — sandbox rules, API, native mapping (collapsible)

Interactive concept on example data only — sandbox memory, nothing syncs or leaves this page. Reset examples (circular-arrow icon) restores the ledger, review, drafts and filters. Currencies never mix in totals; own transfers, pending/failed and unreviewed items are excluded from sums; recording only happens when required facts are valid. Editing keeps the same record ID. Reduced motion honours the system preference and the leaf toggle.

Sandbox logic is adapted from the proven fresh-current-comparison.html script; all seed data, totals invariants and the public API contract (seed, renderAll, entries, review, editingId, totalsFor, toMinor, openAdd, saveDemo, editRow, openDetail, openReviewEdit, resolveReview, show, resetAll, toastSay) are preserved. Native app files (ui/CashflowApp.kt, ui/FlowScreens.kt, ui/theme/CashflowTheme.kt, ui/components/LedgerRow.kt) were not touched. Spec: night-current-design.md.
